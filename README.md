# MotoZone

MotoZone es un proyecto final desarrollado para el curso de Front-End Technologies and User Interface.

El proyecto representa una tienda online de accesorios y productos para motocicletas.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git
- GitHub
- GitHub Pages

## Funcionalidades principales

- Página principal con carrusel de imágenes.
- Diseño responsivo para computadoras, tabletas y teléfonos.
- Menú de navegación.
- Páginas de productos y categorías.
- Efectos al pasar el mouse sobre los productos.
- Botones para mostrar detalles de productos.
- Formulario de contacto con validación mediante JavaScript.
- Uso de elementos semánticos de HTML.
- Estilos personalizados mediante CSS y Bootstrap.

## Páginas del proyecto

- Inicio
- Productos
- Ofertas
- Nosotros
- Contacto
- Motocicletas
- Cascos
- Guantes
- Chaquetas
- Botas
- Accesorios
